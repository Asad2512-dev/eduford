# Architecture

## What this is

Eduford  Landing Page. A premium, production-grade, and fully responsive university landing page built using only semantic HTML5 and vanilla CSS3. The repository has no framework manifest beyond the files listed.

## Layout

- `images/`
- Root files: `index.html`, `README.md`, `style.css`

## How the pieces fit

Static site. HTML files at the root: `index.html`.

## How to run

Commands written in the README:

```

```
